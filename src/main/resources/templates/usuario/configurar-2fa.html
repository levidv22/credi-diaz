Protección de cuenta

Vincular Google Authenticator

Configura la verificación en dos pasos para añadir una capa adicional de seguridad a tu cuenta.

Volver a seguridad

Configuración del autenticador

Vincula tu aplicación y confirma que puedes generar códigos de verificación.

1 Escanea el código QR

Abre Google Authenticator, pulsa el símbolo «+» y selecciona «Escanear un código QR».

2 Usa la clave de configuración

Clave secreta manual

CLAVE SECRETA

Si no puedes escanear el QR, selecciona en la aplicación la opción para introducir una clave de configuración.

No compartas esta clave ni el código QR. Cualquier persona que los tenga podría generar códigos para acceder a tu cuenta.

3. Verifica y activa tu autenticador

Ingresa el código temporal de 6 dígitos que aparece en Google Authenticator para completar la vinculación.

Introduce los seis números sin espacios. El código cambia periódicamente.
